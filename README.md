## 🚀 About The Project

**CC Workplace** is designed to be the ultimate creative ecosystem. Built as a blazing-fast, single-file web application, it ditches boring job boards for an immersive, futuristic UI. Whether you are manipulating studio portraits, designing gaming thumbnails, or writing frontend code, this platform provides the tools to showcase your work, write live code, and connect with clients instantly.

## 🌟 Key Features

*   **🎨 Immersive 3D UI:** A rich dark blue-to-purple gradient theme paired with an interactive **Three.js** particle constellation background that reacts to your cursor.
*   **💻 VS Code-Style Live Studio:** An embedded real-time code editor. Write HTML/CSS/JS and watch the preview update instantly on the canvas. Includes built-in syntax presets for creators!
*   **🚀 GitHub Deployment Hub:** Seamlessly input repository links to generate and test live deployments in seconds.
*   **💎 Interactive Creator Marketplace:** Fluid 3D tilt-effect cards showcasing services for Video Editing, Graphic Design, and Web Development.
*   **🧠 Smart Talent Engine:** An intelligent search and filter system to match clients with the exact creative skills they need.
*   **🔐 Glassmorphism Authentication:** Sleek, animated Sign-In and Registration modals complete with custom, non-blocking toast notifications.

## 🛠️ Tech Stack

This project is highly optimized, running entirely on frontend technologies with zero build-steps required:

*   **Core:** HTML5, CSS3, Vanilla JavaScript (ES6+)
*   **Styling:** Tailwind CSS (via CDN for instant styling)
*   **3D Graphics:** Three.js (Particle engine)
*   **Animations:** Vanilla JS tilt physics & CSS keyframes
*   **Typography & Icons:** Google Fonts (Inter, Fira Code), FontAwesome
